# Order Processing System

A backend order management system for a mid-size retail company. Handles the full lifecycle of
a customer order: creation, discount application, invoice generation, and persistence.

## What it does
- Creates and manages customer orders
- Applies discount rules based on customer tier and order value
- Generates PDF-ready invoice data
- Persists orders to a database (simulated)
- Sends confirmation emails upon successful order placement

## Running
Compile all `.java` files and run `Main.java`.
