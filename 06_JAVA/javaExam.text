5.2 Checked vs Unchecked Exceptions

Checked exceptions: All subclasses from Exception class (except RuntimeException and its subclasses)
Unchecked exceptions (Runtime exceptions): Can be handled but compiler doesn't force try-catch
Difference between unchecked exception and runtime error

5.3 Try-Catch-Finally Blocks

Basic try-catch structure

5.4 Exception Catching Rules (Tricky!)

Exception is only caught once
Duplicate exception catching causes compile errors
Specific exception subclass must precede base exception (otherwise unreachable code error)
General exceptions before specific causes "unreachable code" error
Errors do NOT get caught by catch blocks
